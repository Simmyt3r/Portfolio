## 🎓 Featured Project: The Builder

**"The Builder"** is a free daily tutorial platform for Nigerian teenagers on **tech, business, money, and mindset** — explained like you know absolutely nothing.

### 🎯 Platform Overview

- **Live URL**: [builder.html](./builder.html)
- **Tagline**: *Learn it. Build it. Earn from it.*
- **Target Audience**: Nigerian teenagers aged 13-19 interested in tech, entrepreneurship, and personal growth
- **Content Model**: Free foundational lessons + Premium advanced modules
- **Update Frequency**: New tutorials added daily
- **Created By**: Simeon Tertese, Silabs & Co Technologies

## 🎨 Design & Features

### **Visual Design**
- **Color Scheme**: Navy (#0f2744) + Lime (#a8e63d) accent
- **Typography**: 
  - Display: Syne (400, 600, 700, 800)
  - Body: Manrope (300, 400, 500, 600, 700)
  - Code: JetBrains Mono (300, 400, 500)
- **Responsive**: Optimized for desktop, tablet, and mobile devices
- **Custom Scrollbar**: Lime-colored scrollbar for visual consistency

### **Interactive Features**
- **Track Navigation**: Button-based switching between 4 learning paths
- **Expandable Lessons**: Click headers to reveal/collapse full lesson content
- **Premium Lock System**: Password-protected premium content with unlock modal
- **Smooth Animations**: Staggered fade-in effects (reveal.in animation)
- **Mobile-First Approach**: Fully responsive with touch-friendly UI
- **Collapsible Content**: Max-height transitions for smooth expand/collapse

### **Lesson Structure**
Each tutorial includes:
- 🔢 **Lesson Number & Track Badge**: Track-01, Track-02, etc.
- 💡 **Analogy**: Real-world comparison for understanding
- 📖 **Explanation**: Clear, beginner-friendly content
- 📋 **Key Terms**: Important vocabulary defined with context
- ✅ **Today's Action**: Practical hands-on exercise
- 🔒 **Premium Lock**: Advanced lessons require membership password

### **UI Components**
- **Navigation Bar** - Sticky top nav with back link and CTA button
- **Hero Section** - Eye-catching header with stats display
- **Track Tabs** - 4 interactive buttons for track selection
- **Lesson Cards** - Expandable cards with header, content, and toggle
- **Premium Cards** - Special styling for locked content
- **Lock Overlay** - Modal popup for password entry
- **Footer** - Simple branding and copyright
